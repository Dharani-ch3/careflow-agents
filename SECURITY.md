# Security

This repository is a demonstration and uses synthetic data only. It is **not** cleared
for use with real patient information as-is. See "What's deliberately not here" in the
README for the gaps you'd need to close first.

If you find a security issue in the code, such as a way to make a tool act on another
patient's records, or PII reaching a prompt or a log, please don't open a public issue.
Instead, use GitHub's private vulnerability reporting
("Security" tab → "Report a vulnerability"). I'll reply as soon as I can.
